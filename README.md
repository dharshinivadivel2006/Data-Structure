Customer Service System

Abstract
The Customer Service System is a simple Python-based project that manages customer requests using the Queue data structure.

Problem Statement
Managing customer requests manually can be difficult and time-consuming. This system helps serve customers in the correct order.

Objectives
- To manage customer requests.
- To add new customers.
- To display pending customers.
- To serve customers in order.

Data Structure Used
**Queue (FIFO)**

FIFO means First In, First Out. The customer who comes first will be served first.

Technologies Used
- Programming Language: Python
- Data Structure: Queue

Modules
1. Add Customer
2. View Customers
3. Serve Customer
4. Exit

Conclusion
This project demonstrates how the Queue data structure is used in a real-time customer service system.
